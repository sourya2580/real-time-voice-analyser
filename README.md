# 🎙️ Real-Time Voice Analyser

> Processes and analyses live audio streams in real time.

## 📌 Problem
Raw audio is hard to interpret instantly — users need immediate insight from live voice input.

## 💡 Solution
Captures live microphone input and analyses it in real time, processing audio signals as they arrive.

## ⚙️ Tech Stack
- **Language:** Python
- **Concepts:** Audio Processing, Real-Time Data Streams

## 🧠 Key Learnings
- Handling live audio buffers without latency
- Signal processing fundamentals
- Working with real-time data pipelines

## 🔧 How to Run
```bash
git clone https://github.com/sourya2580/voice-analyser
cd voice-analyser
pip install -r requirements.txt
python analyse.py
```
